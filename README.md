# chord-predictor
Software that recognizes, classifies, and predicts guitar chords for different genres.

## Environment Setup

Prerequisite: You'll need Node.js installed.

1. Clone the repository:
   `git clone https://github.com/xericue/chord-predictor.git`

2. Get to the correct directory:
   `cd front\chord-predictor-website`

## Installation

1. Install the dependencies:
   `npm install`

2. Start the app
   `npm start`
   This should bring you to `http://localhost:3000`
